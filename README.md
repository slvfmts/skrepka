# skrepka 📎

Ваш ИИ-соавтор в Google Документах.

ИИ-агент из вашего терминала читает комментарии заказчика, отвечает на них и правит текст. Комментарии и оформление остаются на месте.

[In English](README.en.md) · [Приватность](PRIVACY.md) · [Безопасность](SECURITY.md)

## Зачем

Когда программа правит Google Документ, легко потерять комментарии. Вы поменяли текст, и комментарии заказчика исчезли из документа. skrepka так не делает. Она идёт только безопасными путями, а операцию, которая потеряла бы чью-то работу, отклоняет и объясняет причину.

## Для кого

Для редакторов, копирайтеров и контент-менеджеров. Вы ведёте документы с заказчиками в Google Docs и работаете через ИИ-агента, например Claude Code или Codex. Разработчиком быть не нужно, доступ настраивает мастер `skrepka init`.

## Что умеет

Чаще всего skrepka нужна, чтобы разобрать комментарии заказчика и поправить текст на месте. Вы говорите агенту «отработай комментарии», он читает треды, отвечает по делу и вносит правки. Треды закрываете вы сами, агент их не резолвит.

Ещё skrepka выгружает документ в markdown и заливает правки обратно, создаёт документы из markdown и разбирает предложенные правки. Полный список сценариев собран в docs/PLUGIN.md.

## Как начать

1. Поставьте skrepka: `pipx install skrepka`.
2. Настройте доступ к Google: `skrepka init`. Мастер проведёт по шагам за 15–30 минут. Подробная инструкция со снимками экрана лежит в docs/QUICKSTART.md.
3. Подключите навыки к агенту, например Claude Code или Codex: docs/PLUGIN.md.

После этого попросите агента отработать комментарии в тестовом документе.

Вы заводите собственный проект Google и работаете от своего имени. У skrepka нет сервера, она не хранит и не видит ваши данные. Подробнее об этом в PRIVACY.md.
